Консольное приложение «Библиотека» на C# / .NET 10 — учебный проект по дисциплине «Основы работы с технической документацией».

## Возможности

- 📚 Хранение списка книг и читателей в памяти.
- 📖 Выдача книги читателю с проверкой занятости.
- 📝 Просмотр истории выдач.
- ✅ Проверка ошибок: книга не найдена, читатель не найден, книга уже выдана.
- 🧾 Полная XML-документация всех публичных членов.
- 📊 Диаграммы классов и последовательности в формате Mermaid.

## Системные требования

- **ОС:** Windows 10 (1903+) / 11, Ubuntu 22.04+, macOS 12+
- **.NET Runtime:** 10.0 или новее (или .NET SDK 10.0 для сборки из исходников)
- **Терминал** с доступом к команде `dotnet`
- **ОЗУ:** от 512 МБ
- **Свободное место:** от 100 МБ

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Alim070707/LibraryApp.git
cd LibraryApp
```

### 2. Сборка

```bash
dotnet build
```

### 3. Запуск

```bash
dotnet run
```

После запуска появится главное меню.

## Использование

Программа работает в интерактивном режиме. После запуска отображается меню:

```
=== Библиотека ===
1 — список книг
2 — выдать книгу
3 — список выдач
0 — выход
Выбор:
```

### Основные сценарии

**Просмотр списка книг:**
1. Введите `1` и нажмите Enter.
2. Отобразится список всех книг с указанием, выдана книга или доступна.

**Выдача книги читателю:**
1. Введите `2` и нажмите Enter.
2. Введите `Id` книги (например, `1`).
3. Введите `Id` читателя (например, `1`).
4. При успехе отобразится сообщение `Успешно: Выдача #1: ...`.

**Просмотр истории выдач:**
1. Введите `3` и нажмите Enter.
2. Отобразится список всех записей о выдачах.

**Выход из программы:**
- Введите `0` и нажмите Enter.

## XML-документация

В файле `LibraryApp.csproj` включена генерация XML-файла документации:

```xml
<GenerateDocumentationFile>true</GenerateDocumentationFile>
```

Все публичные классы, интерфейсы, методы и свойства снабжены XML-комментариями (`///`). Они отображаются в IntelliSense при наведении на вызов метода или свойства.
